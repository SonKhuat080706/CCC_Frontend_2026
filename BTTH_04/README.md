# BTTH_04 — React Exercises Solutions

Bộ bài này hoàn thành các bài tập trong file `BTTH_04.zip`.

## 1. Bài CDN, không cần cài đặt

Mở trực tiếp bằng trình duyệt:

```text
cdn_exercises/vanilla.html
cdn_exercises/react_demo.html
cdn_exercises/portfolio_hero.html
cdn_exercises/portfolio_projects.html
cdn_exercises/shop_components.html
```

## 2. Project Portfolio React/Vite

Thư mục:

```text
session_04_portfolio_react/
```

Chạy:

```bash
cd session_04_portfolio_react
npm install
npm run dev
```

Project này hoàn thành:

- Exercise 4.1 — React Components Setup
- Exercise 4.2 — State + Props
- Exercise 4.3 — Category Filter + Events
- Exercise 4.4 — Contact Form với useState

## 3. Project Tier Practice

Thư mục:

```text
tier_react_practice/
```

Chạy:

```bash
cd tier_react_practice
npm install
npm run dev
```

Project này tổng hợp các bài:

- Tier 0 — Component đầu tiên
- Tier 1 — React Flow
- Tier 2 — JSX variables, conditional rendering, list rendering
- Tier 3 — Component split + props
- Tier 4 — useState cơ bản
- Tier 5 — Events
- Tier 6 — Lists & CRUD
- Tier 7 — Todo App hoàn chỉnh

## 5. Ghi chú

Các project dùng Vite + React. File `package.json` đã có sẵn, nhưng chưa cài `node_modules` trong zip để tránh nặng file. Chỉ cần chạy `npm install`.
