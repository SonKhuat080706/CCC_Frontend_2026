# Hướng dẫn chạy

## CDN files

Mở trực tiếp:

```bash
start cdn_exercises/vanilla.html
start cdn_exercises/react_demo.html
start cdn_exercises/portfolio_hero.html
start cdn_exercises/portfolio_projects.html
start cdn_exercises/shop_components.html
```

Trên Linux/WSL có thể dùng:

```bash
python3 -m http.server 8000
```

rồi mở `http://localhost:8000`.

## Portfolio Vite project

```bash
cd session_04_portfolio_react
npm install
npm run dev
```

## Tier Vite project

```bash
cd tier_react_practice
npm install
npm run dev
```

## Ghi chú

Nếu dùng WSL, mở link dev server do Vite in ra, thường là:

```text
http://localhost:5173
```
